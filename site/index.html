📖 Benchmark Methodology & Reproducibility

Measurement Protocol

  • Every benchmark implementation generates numbers 0..999,999 and writes formatted lines to standard output redirected to /dev/null.
  • All runs execute inside an unprivileged Alpine Linux container (benchmarks-env) using the same kernel and CPU allocation.
  • Naive Mode: Uses standard idiomatic language print/loop statements with standard defaults.
  • Optimized (Race Mode): Uses maximal chunked buffered I/O, syscall batching, release compiler optimizations (-O3, --release), and fast integer formatting.

How to Run Locally

# Build container image with all runtimes
make build-env

# Execute the full benchmark suite
make bench

# Generate static dashboard into public/
make site
